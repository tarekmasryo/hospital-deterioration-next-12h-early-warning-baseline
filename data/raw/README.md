# data/raw

Place the dataset CSV files here when running the notebook locally.

Raw data is intentionally not committed to the repository.

## Required files

```text
patients.csv
vitals_timeseries.csv
labs_timeseries.csv
hospital_deterioration_hourly_panel.csv
hospital_deterioration_ml_ready.csv
```

## Kaggle usage

On Kaggle, the notebook automatically searches under:

```text
/kaggle/input/
```

No hard-coded Kaggle dataset slug is required.
